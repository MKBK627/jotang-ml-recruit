# Task 1

## make_moons
`make_moons` 是 sklearn 中用来生成二维二分类数据集的函数。它生成的数据大致呈两个弯月形，因此不是简单线性可分的数据，比较适合用来测试神经网络能否学习非线性决策边界。

## noise
`noise`用来控制生成数据中的随机扰动程度。
noise 越小，两个月牙的数据分布越整齐；
noise 越大，样本之间会出现更多重叠，分类难度也会增加。

## random_state
`random_state`用于固定随机过程。可以让` make_moons `每次生成相同的数据，也可以让数据集划分的结果保持一致，方便重复实验和比较实验结果。
**random_state 只能控制 sklearn 中的随机过程。**
PyTorch 中模型参数初始化也具有随机性，因此还需要使用：
`torch.manual_seed(42)`来固定 PyTorch 的随机种子。

## stratify
`stratify `用来让划分后的训练集、验证集和测试集尽量保持原始数据中的类别比例。其可以避免某个数据集中某一类别过多或过少，使不同数据集的类别分布更加稳定。

## 超参数
`超参数`是模型训练之前人为设置的参数

## 训练集、验证集和测试集
- 训练集：用于训练模型，模型会根据训练集不断调整参数。
- 验证集：用于训练过程中观察模型效果和选择超参数，不直接参与最终测试。
- 测试集：用于模型训练和调参结束后，评价模型面对未见数据时的最终性能。为了避免数据泄漏，测试集只在最终评价模型时使用，不参与模型训练和超参数选择。

## NumPy数组与Tensor
`NumPy `数组和` PyTorch Tensor `都可以用来存储多维数据。
Task1中，make_moons 生成的 X 和 y 一开始是 NumPy 数组。
为了让数据能够送入 PyTorch 神经网络中训练，需要将它们转换为 Tensor。

## 一轮训练
1. optimizer.zero_grad()
   清空上一轮留下的梯度

2. outputs = model(X_train)
   把训练数据送进模型，得到预测结果
   → 这就是前向传播

3. loss = criterion(outputs, y_train)
   把预测结果和真实标签比较
   → 算出模型“错了多少”

4. loss.backward()
   根据 loss 反向计算每个参数的梯度
   → 这就是反向传播

5. optimizer.step()
   根据梯度真正修改模型参数

## 错误样本分析

本次测试集中共有 5 个样本被错误分类。

从可视化结果可以看到，错误样本大多位于两类数据分布的边界附近，或者落在另一类别样本较密集的区域。这些样本本身具有较强的混淆性，因此模型更容易判断错误。

另外，数据生成时设置了 `noise=0.2`，部分样本会偏离原本较规则的月牙形结构，这也会增加分类难度。

## 趁热打铁

### 1.你在这个任务之中，选择了什么激活函数，为什么选这个？
我选择了ReLU激活函数。
因为`make_moons`数据并不是简单线性可分的，需要神经网络具备非线性表达能力，而ReLU可以为隐藏层加入非线性。而且ReLU计算简单、训练效率较高。

### 2.你选择了什么损失函数？为什么？那如果这一题是三分类问题呢？
我选择了`CrossEntropyLoss`损失函数。
因为本题是二分类任务，而CrossEntropyLoss会根据模型对各类别的输出和真实标签之间的差异计算损失，能够直接用于多分类问题，因此适合本题。
如果是三分类问题需要把模型最后一层从`nn.Linear(hidden_size, 2)`改为`nn.Linear(hidden_size, 3)`。

### 3.optimizer.zero_grad()、loss.backward() 和 optimizer.step() 分别完成了什么工作？如果不清空梯度会发生什么？
`optimizer.zero_grad()` 用于清空上一轮训练留下的梯度。
`loss.backward()` 用于进行反向传播，根据当前损失计算模型各参数的梯度。
`optimizer.step()` 根据计算得到的梯度和学习率等规则，真正更新模型参数。
**如果不调用 optimizer.zero_grad() 清空梯度，PyTorch 会把这一轮计算得到的梯度继续累加到上一轮梯度上，导致参数更新不符合预期，可能使训练过程变得不稳定。**

即
>- `zero_grad()`：先把上一轮的梯度清掉；
>- `backward()`：计算这一轮各参数应该往哪个方向调整；
>- `step()`：按照这些梯度真正更新参数。


### 4.更深、更宽的神经网络一定能取得更好的效果吗？模型过于简单或过于复杂分别可能带来什么问题？
不一定。

增加网络深度或宽度可以提高模型的表达能力，让模型有能力学习更复杂的规律，但模型变复杂后，也会带来更多参数和更高的计算开销。
如果模型过于复杂，而数据量又比较少，还可能更容易出现过拟合，也就是训练集表现很好，但验证集或测试集表现变差。
在本次实验中，当我将隐藏层宽度从8增加到16和32之后，训练损失整体有所下降，但验证集准确率并没有一直提高，这也说明网络更宽并不一定在所有指标上都更好。

因此，网络结构需要根据具体任务和数据规模来选择，而不是越深越宽越好。

### 5.学习率过大或过小会怎样影响模型训练？你能从 loss 曲线中观察到哪些现象？
学习率决定了模型每次更新参数时调整的幅度。

如果学习率过小，模型每次参数更新的幅度很小，Loss 会下降得比较慢，需要更多训练轮数才能收敛；如果学习率过大，参数每次变化幅度过大，可能会跨过较优的位置，使 Loss 出现明显波动，严重时甚至可能无法收敛。

在本次实验中，学习率为 0.001 时，训练 500 个 epoch 后 Loss 仍然较高，说明收敛速度较慢；学习率为 0.01 和 0.1 时，Loss 下降更快，最终分类效果也更好。

因此，通过观察 Loss 曲线，可以判断模型的收敛速度、训练是否稳定，以及学习率是否可能设置得过大或过小。

### 6.假设还有一个分类问题，但是两个类别的样本数量非常不均衡，训练出来的模型会怎么样？为什么？说明了什么？ 你可以尝试构造一个数据集试试看
如果两个类别的数据数量相差很大，模型在训练时可能会更倾向于预测样本数量较多的类别。
例如，如果一共有 1000 个样本，其中 950 个属于类别 0，只有 50 个属于类别 1，那么模型即使几乎全部预测成类别 0，也可能得到很高的准确率。
这种情况下，只看 Accuracy 可能会产生误导，因为模型虽然整体准确率很高，但对少数类别的识别效果可能很差。

因此，在类别不平衡的问题中，除了 Accuracy，还应该结合混淆矩阵、Precision、Recall、F1-score 等指标来判断模型效果。这说明评价一个分类模型时，不能只依赖单一的准确率指标，还需要结合数据分布和具体任务进行分析。

### 7.如果想要过拟合这个数据集，你会怎么做？为什么？试试看能不能实现吧！（在别的数据集也可以）训练过程和数据呈现和正常训练有何不同？你通过什么判断他过拟合？
如果想让模型更容易出现过拟合，可以使用更复杂的网络、增加训练轮数，或者减少训练数据量，让模型更容易记住训练集中的样本。

发生过拟合时，通常会出现这种现象：

- 训练集 Loss 持续下降；
- 训练集 Accuracy 很高；
- 但验证集 Accuracy 不再提高，甚至开始下降；
- 训练集和验证集之间的性能差距越来越大。

因此，可以通过同时观察训练集和验证集的 Loss、Accuracy 曲线来判断模型是否出现过拟合。

过拟合说明模型虽然很好地适应了训练数据，但对没有见过的数据泛化能力较差。
